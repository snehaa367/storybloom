# Storybloom — Interactive Digital Storybook

Storybloom is an interactive bedtime storybook web application crafted with React, Vite, HTML, and CSS. It offers an immersive, dreamy sanctuary with bespoke watercolor illustrations, calming ambient procedural soundscapes, dynamic atmospheric animations, and an interactive Story Oracle.

## Features

- **Illustrated Library**: 15 complete, curated bedtime tales across themes of Wonder, Calm, Fantasy, Courage, Adventure, and Hope.
- **Dual-Page Story Reader**: A book-spread layout with page-turn transitions, font size adjustments, keyboard navigation (`ArrowLeft` / `ArrowRight`, `Esc`), and reading progress persistence.
- **Story-Specific Animations**: Lightweight HTML5 Canvas particle systems customized for each tale (stars, falling leaves, gears, fireflies, drifting clouds).
- **Procedural Ambient Soundscapes**: Native Web Audio API procedural music and wind chime generators with volume and mute controls, requiring zero external audio assets.
- **Story Oracle**: A mood-based discovery ritual that recommends stories attuned to what the reader's heart needs.
- **Ribbon Bookmarks**: Save stories to a personal bookmark drawer stored in `localStorage`.
- **Responsive & Accessible**: Dark lavender palette with responsive layouts for mobile, tablet, and desktop, plus reduced-motion support.

## Tech Stack

- **React 19**
- **Vite**
- **Framer Motion**
- **Lucide React**
- **Web Audio API**
- **HTML5 Canvas**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
